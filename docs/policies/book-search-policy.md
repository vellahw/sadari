# 도서 검색 및 외부 API 쿼터 보호 정책

## 개요

- 기준일은 2026년 8월 28일입니다.
- 로그인 회원이 Kakao 도서 검색 API를 사용하는 화면과 서버의 호출 제한, 캐시 및 인기 검색어 처리에 적용합니다.
- 외부 API 일일 쿼터를 효율적으로 사용하고 한 회원의 반복 요청이 전체 서비스 검색 기능이나 인기 검색어 순위를 독점하지 않게 하는 것이 목적입니다.

## 접근 범위

- 도서 검색 화면과 `GET /api/book/search`는 로그인한 `활성` 회원만 사용할 수 있습니다.
- 비로그인 요청은 Spring Security 인증 단계에서 차단합니다.
- `비활성화`, 영구 탈퇴 대기 및 `이용정지` 상태는 기존 계정 상태 접근 제한을 적용하므로 도서 검색을 사용할 수 없습니다.
- 클라이언트가 보낸 회원 번호를 신뢰하지 않고 인증된 회원 번호를 요청 제한 기준으로 사용합니다.

## 검색 결과 조회

1. 서버는 카카오 도서 검색 API 한 번에 최대 50권을 요청합니다.
2. 화면은 받아둔 결과 중 처음 10권만 표시합니다.
3. 사용자가 목록 하단에 도달하면 이미 받은 결과에서 10권씩 추가로 표시합니다.
4. 받아둔 50권을 모두 표시한 뒤에만 다음 카카오 검색 페이지를 호출합니다.
5. 카카오 응답의 `meta.is_end`가 마지막 페이지이면 빈 다음 페이지를 호출하지 않습니다.

10권 단위로 카카오 API를 직접 호출하던 구조와 비교하면 50권을 확인하는 데 필요한 외부 호출 수는 최대 5회에서 1회로 감소합니다. 이는 소스 호출 구조에서 계산한 값이며 네트워크 응답 시간 개선을 측정한 결과는 아닙니다.

## 영어 도서 검색 준비

- 영어 도서 검색 공급자는 Google Books API를 사용합니다.
- 같은 ISBN이라도 한국어와 영어의 제목, 저자, 출판사, 표지, 설명을 별도 도서 정보로 저장할 수 있습니다.
- ISBN과 도서 정보 언어의 조합은 중복 저장하지 않으며, 내부 도서 식별값은 기존 방식대로 유지합니다.
- 도서 평균 평점과 인기 도서 평점은 도서 정보 언어로 나누지 않고 같은 ISBN에 연결된 모든 언어의 완료·중단 독후감을 합산합니다.
- 도서 정보는 회원별 데이터가 아닌 공유 데이터이므로 계정 비활성화, 영구 탈퇴 신청·취소와 회원 물리 삭제로 제거하지 않습니다.
- 이번 단계에서는 한국어·영어 도서 정보를 함께 저장할 데이터 구조만 준비하며 Google Books API 호출, 인증 정보와 검색 화면 전환은 후속 단계에서 적용합니다.

## 검색 화면 진입 출처

- 공용 도서 검색 화면은 일반 독후감 등록, 독서 타이머 및 독서 모임의 진입 출처를 화면 이동 상태로 구분합니다.
- 일반 독후감 등록 출처에서 도서를 선택하면 기존 동일 ISBN 독후감 확인 후 수정 또는 추가 등록 흐름을 유지합니다.
- 독서 타이머 출처에서 도서를 선택하면 검색 화면 위에 별도 설명과 입력 항목명 없이 오늘부터 목표일까지 걸리는 일수를 왼쪽 `-`, 오른쪽 `+`로 설정하는 타이머 전용 팝업을 표시합니다. 하단에는 독서 목표 설정 팝업과 같은 `닫기`와 `확인` 명령만 표시하고 단계 진행 표시는 두지 않으며, 확인 시 기존 독후감 등록 API로 `읽는 중` 상태 독후감을 생성합니다.
- 독서 타이머 출처의 목표일 팝업을 닫거나 등록을 완료하면 `/timer`로 돌아가 현재 읽는 책 선택 팝업을 다시 표시합니다. 등록 완료 시에는 타이머 요약을 강제로 다시 조회하고 새 독후감 번호를 선택 상태로 전달해 방금 추가한 책을 즉시 표시합니다.
- 화면 이동 상태는 서버에 임시 초안으로 저장하지 않으며 새로고침 또는 다른 경로 이탈 뒤 미확정 도서와 기간을 복원하지 않습니다.
- `비활성화`, 영구 탈퇴 대기 및 `이용정지` 상태에서는 진입 출처와 관계없이 도서 검색과 후속 등록을 모두 허용하지 않습니다.

## 기간별 인기 도서

- 검색 화면에 처음 진입하고 복원할 직접 검색 결과가 없으면 `GET /api/book/popular?period=monthly`로 월간 인기 도서를 최대 10권 조회합니다.
- 사용자는 검색 입력창 아래 오른쪽의 선택 목록에서 `weekly`, `monthly`, `yearly`에 해당하는 주간·월간·연간 인기 도서를 변경할 수 있습니다.
- `Asia/Seoul` 기준으로 주간은 현재 주 월요일부터 다음 월요일 전까지, 월간은 현재 달 1일부터 다음 달 1일 전까지, 연간은 현재 연도 1월 1일부터 다음 연도 1월 1일 전까지 독후감의 등록 일시를 집계합니다.
- 회원 상태, 독서 상태 및 독후감 공개 여부와 관계없이 독후감에 남아 있는 모든 독후감을 집계합니다.
- 작성자 수가 많은 도서부터 정렬하고, 동률이면 가장 최근 독후감 등록 시각과 도서 번호 순으로 정렬해 1위부터 10위까지 순위를 부여합니다.
- 인기 도서 평균 평점은 도서 정보 화면과 동일하게 읽는 중인 독후감을 제외하고 공개 여부와 관계없이 해당 도서의 전체 완료·중단 독후감 평점으로 계산합니다.
- 인기 도서 카드는 도서 소개를 표시하지 않고 출판사 위치에 도서 정보 화면과 같은 별 아이콘 및 평균 평점을 표시합니다. 순위와 작성자 수는 도서 표지 아래와 제목 위에 표시합니다.
- 직접 검색 결과는 기존 출판사와 세 줄 도서 소개를 유지하며, 검색 결과가 반환되면 인기 검색어, 인기 도서 기간 선택, 순위, 작성자 수 및 평균 평점을 숨깁니다.

## 인기 검색어

- 검색 화면은 `GET /api/book/popular-search-keywords`로 최근 인기 검색어를 최대 10건 조회합니다.
- 인기 도서 모드에서는 검색 입력창 아래의 고정된 한 줄에서 인기 검색어를 왼쪽에, 인기 도서 기간 선택을 오른쪽에 같은 높이로 표시하며 검색어 한 건씩 아래에서 위로 교체합니다.
- 인기 도서 기간 선택을 펼치면 목록에는 `주간`, `월간`, `연간`만 표시하고 닫힌 상태에는 선택한 기간과 `인기 도서` 문구를 함께 표시합니다.
- 검색어가 한 줄의 남은 너비보다 길면 가로 스크롤이나 줄바꿈 없이 말줄임표로 표시합니다.
- 검색어 자동 교체 간격은 3.2초이며 마우스를 올리거나 키보드 포커스가 들어오면 현재 검색어에서 교체를 멈춥니다.
- 동작 줄이기 환경설정을 사용하는 화면에서는 세로 이동 애니메이션을 적용하지 않습니다.
- 사용자가 현재 검색어를 클릭하거나 터치하면 해당 값을 검색 입력창에 반영하고 첫 페이지를 즉시 조회합니다.
- 비속어를 포함한 검색어도 Kakao 도서 검색에는 그대로 사용할 수 있으며 비속어가 있다는 이유로 검색 실패 응답을 반환하지 않습니다.
- 결과가 한 권 이상인 첫 페이지 검색만 인기 검색어 후보로 집계하며 추가 페이지와 결과가 없는 검색은 제외합니다.
- 공용 검색 결과 캐시에 적중한 검색도 실제 회원의 검색 의도이므로 집계 대상에 포함합니다.
- 검색어는 Unicode NFKC로 변환하고 앞뒤 공백, 연속 공백과 영문 대소문자를 정규화한 뒤 집계합니다.
- 운영에서는 같은 회원의 같은 정규화 검색어를 기본 최근 7일에 한 번만 점수에 반영합니다.
- 로컬 프로필은 한 계정으로 순위와 슬라이드 화면을 검증할 수 있도록 회원별 중복 제한을 해제하고 같은 검색어의 반복 검색을 매번 점수에 반영합니다.
- 기본 최근 7일의 날짜별 Redis Sorted Set 점수를 합산하고 고유 회원 점수가 3 이상인 검색어만 표시합니다.
- 인기 검색어 최대 건수, 집계 일수와 최소 고유 회원 수는 공개 가능한 운영 환경변수로 관리합니다.
- 길이가 2자 미만이거나 40자를 초과하는 검색어와 이메일, 전화번호 및 URL 형태는 공용 인기 검색어에 표시하지 않습니다.
- 기존 `BadWordDetectionService`로 정규화 검색어와 모든 공백을 제거한 값을 모두 검사하여 공백 삽입 우회 표현도 인기 검색어에서 제외합니다.
- Redis 점수 반영 전과 화면 조회 시점에 비속어를 각각 검사하므로 집계 뒤 비속어 사전이 변경된 검색어도 다음 조회부터 표시하지 않습니다.
- 일별 점수에는 화면 표시를 위한 정규화 검색어 원문을 기본 8일간 저장하고 회원별 중복 방지 정보에는 검색어 SHA-256 해시와 집계 시각만 저장합니다.
- 인기 검색어 집계나 조회가 실패해도 도서 검색과 기간별 인기 도서는 유지하며 인기 검색어 영역만 숨깁니다.

## 검색 입력 실행

- 검색어 한 글자는 자동 검색하지 않으며 검색 버튼 또는 Enter로 직접 조회할 수 있습니다.
- 검색어 두 글자 이상은 모바일 키보드가 열린 상태에서도 입력 변경이 멈춘 100ms 뒤 자동 조회합니다.
- 검색 버튼 또는 Enter를 누르면 예약된 자동 검색을 취소하고 현재 검색어를 즉시 조회합니다.
- 이미 조회했거나 조회 중인 동일 검색어는 자동 검색과 수동 제출 사이에서 중복 호출하지 않습니다.
- 검색어를 모두 지우면 직접 검색 세션 캐시를 제거하고 현재 기간의 인기 도서 및 인기 검색어 화면으로 돌아갑니다.

## 회원별 요청 제한

| 제한 | 기본값 | 집계 대상 | 만료 |
| --- | ---: | --- | --- |
| 캐시 적중 단기 요청 | 60초당 300회 | 공용 캐시 결과를 반환하는 회원 요청 | 첫 허용 요청부터 60초 |
| 캐시 미적중 단기 요청 | 60초당 60회 | 공용 캐시에 없어 카카오 API 호출 후보가 되는 회원 요청 | 첫 허용 요청부터 60초 |
| 일간 외부 호출 | 24시간당 200회 | 공용 캐시 미적중으로 카카오 API를 실제 호출하는 회원 요청 | 첫 실제 호출 예약부터 24시간 |

- 캐시 적중과 미적중 요청은 서로 영향을 주지 않는 Redis 단기 카운터로 각각 검사합니다.
- 캐시 적중 요청은 높은 300회 한도로 Redis와 응답 트래픽의 과도한 사용만 제한하며 카카오 쿼터를 차감하지 않습니다.
- 캐시 미적중 요청은 60회 한도로 카카오 API의 짧은 시간 반복 호출을 제한합니다.
- 공용 캐시 미적중 시 회원별 일간 및 앱 전체 실제 호출 카운터를 Redis Lua Script에서 함께 검사하고 허용된 요청만 원자적으로 증가시킵니다.
- 공용 캐시 적중 요청은 회원별 일간 및 앱 전체 실제 호출 카운터를 증가시키지 않습니다.
- 제한을 초과하면 카카오 API를 호출하지 않고 “검색 요청이 너무 많아요. 잠시 후 다시 시도해주세요.” 메시지를 반환합니다.
- Redis 장애로 제한을 확인할 수 없으면 외부 쿼터 보호를 우선하여 도서 검색을 일시적으로 차단합니다.
- 제한값은 운영 환경변수로 조정할 수 있으며 변경된 값은 새 요청부터 적용합니다.

## 앱 전체 쿼터 보호

- 공용 캐시에 없는 검색으로 카카오 API를 실제 호출하기 직전에 앱 전체 카운터를 예약합니다.
- 기본 24시간 실제 호출 한도는 27,000회입니다.
- 카카오 도서 검색 일일 제공량 30,000회 중 3,000회는 운영 확인과 비상 대응을 위해 남깁니다.
- 카카오 요청이 오류 응답을 반환해도 공급자 쿼터가 사용됐을 가능성이 있으므로 예약한 횟수를 되돌리지 않습니다.
- 공용 캐시에 적중한 요청은 카카오 API를 호출하지 않으므로 앱 전체 실제 호출 카운터를 증가시키지 않습니다.

## 공용 검색 결과 캐시

- 같은 검색어와 카카오 페이지의 응답은 Redis에 기본 10분간 저장합니다.
- 캐시 키에는 검색어 원문을 기록하지 않고 정규화한 검색어와 페이지를 SHA-256으로 변환한 값을 사용합니다.
- 캐시 값에는 카카오가 반환한 공개 도서 정보와 페이지 메타정보만 저장하며 회원 번호, 검색 회원, 선택한 도서 및 독후감 정보를 포함하지 않습니다.
- 캐시 저장에 실패해도 이미 받은 카카오 응답은 사용자에게 반환하지만, 다음 동일 검색은 새 외부 호출 한도 예약이 필요합니다.
- 캐시 조회값이 없거나 복원할 수 없으면 앱 전체 호출 한도를 다시 검사한 뒤에만 카카오 API를 호출합니다.

## 계정 수명주기

- 계정 비활성화와 영구 탈퇴 신청 시 회원별 분간 및 일간 제한 카운터는 기존 TTL까지 유지합니다.
- 재로그인으로 계정을 활성화하거나 영구 탈퇴를 취소해도 남은 제한 횟수와 만료시간을 초기화하지 않습니다.
- 유예기간이 지나 회원이 물리 삭제되면 회원별 제한 키를 즉시 삭제합니다.
- 공용 검색 결과 캐시는 사용자와 연결되지 않으므로 계정 비활성화, 영구 탈퇴 신청·취소 및 물리 삭제로 변경하지 않고 TTL 만료까지 유지합니다.
- 계정 비활성화와 영구 탈퇴 신청 중에는 기존 계정 접근 제한으로 신규 검색과 인기 검색어 점수 반영을 중단합니다.
- 회원별 인기 검색어 중복 방지 정보는 계정 비활성화, 영구 탈퇴 신청과 취소 및 재활성화로 초기화하지 않고 기본 최근 7일의 TTL까지 유지합니다.
- 비활성화 또는 삭제 대기 전에 반영된 인기 검색어 점수는 회원 식별값과 연결되지 않은 일별 합산 데이터이므로 상태 변경 시 차감하거나 복원하지 않고 기본 8일 안에 자동 만료합니다.
- 유예기간이 지나 회원이 물리 삭제되면 회원 번호와 연결된 인기 검색어 중복 방지 키를 즉시 삭제하지만 익명 일별 점수는 남은 TTL까지 유지합니다.
- 도서 검색 제한과 캐시는 독후감 공개 범위, 댓글, 알림, 푸시 구독 및 소셜 관계를 변경하거나 복원하지 않습니다.
- 주간·월간·연간 인기 도서 집계는 `활성`, `비활성화`, 영구 탈퇴 대기, `이용정지` 등 회원 상태를 조건으로 사용하지 않습니다.
- 계정 상태가 변경되어도 독후감에 독후감이 남아 있는 동안에는 모든 기간의 인기 도서 작성자 수와 평균 평점에 포함합니다.
- 유예기간이 지나 회원과 독후감이 물리 삭제되면 해당 독후감은 모든 기간 집계에서 영구 제외되며 별도 인기 순위 또는 평균 평점 이력으로 복원하지 않습니다.
- 기간별 인기 도서 조회는 독후감 공개 설정, 댓글, 알림, 푸시 구독 및 소셜 관계를 변경하지 않습니다.
- 인기 검색어 집계와 클릭 검색은 독후감 공개 설정, 댓글, 알림, 푸시 구독 및 소셜 관계를 변경하지 않습니다.

## 실패 및 운영 확인

- 회원 제한 또는 앱 전체 제한에 도달하면 업무 코드 도서 검색 한도 초과 오류를 반환합니다.
- 카카오 인증, 통신 또는 응답 계약 오류는 기존 공통 검색 실패 응답으로 처리하고 원시 외부 응답과 API 키를 노출하지 않습니다.
- 운영 Redis에서는 `KEYS` 명령을 사용하지 않고 제한 키의 TTL과 개별 카운터 또는 `SCAN`으로 상태를 확인합니다.
- 쿼터 제한값을 변경하면 `application-prod.yml`, `.env.example`, GitHub Actions Variables와 배포 문서를 함께 갱신합니다.
