# 계정 비활성화 및 영구 탈퇴 정책

## 적용 범위

- 기준일은 2026년 8월 27일입니다.
- 사용자 계정 비활성화, 복귀, 영구 탈퇴 유예·취소·삭제와 관리자 계정 처리 이력 조회에 적용합니다.
- 설치형 웹앱의 정적 리소스 업데이트가 계정 상태에 미치는 영향도 적용 범위에 포함합니다.
- 설치형 웹앱 설치 권장 알럿 확인 일시의 보존·삭제 기준도 적용 범위에 포함합니다.
- 독서 모임 기능이 출시된 뒤 적용할 모임장 부재·승계 연계 기준은 별도 절에 구분해 기록합니다.
- 개인 차단 관계의 보존·삭제 항목은 현재 데이터 저장과 서버 검증에 적용합니다.

## 공통 절차

1. 사용자가 계정 비활성화 또는 영구 탈퇴와 처리 사유를 선택합니다.
2. `OTHER` 사유를 선택하면 상세 사유를 필수로 입력합니다.
3. 상세 탈퇴 사유는 UTF-8 기준 최대 500바이트까지 입력할 수 있습니다.
4. 서버가 계정 처리 유형과 사유를 공통코드로 검증합니다.
5. 사용자가 최종 확인창에서 확인한 경우에만 재인증 요청을 생성합니다.
6. 탈퇴 요청은 예측 불가능한 OAuth `state`와 함께 Redis에 10분간 저장합니다.
7. Kakao 재인증 계정과 현재 로그인 계정이 일치해야 탈퇴를 진행합니다.
8. Kakao 연결 해제 성공 후 로컬 탈퇴 상태를 적용합니다.

확인창에서 취소하면 재인증 API를 호출하지 않으며 Kakao 화면으로 이동하지 않습니다.

화면의 비활성화와 영구 탈퇴 선택 카드에는 각 정책의 핵심 안내 한 줄만 표시하며, 도움말 버튼을 누르면 전체 정책을 비교할 수 있는 안내 팝업을 제공합니다.

도움말 팝업의 비활성화 목록은 사용자 안내 팝업 콘텐츠의 계정 문의·`WITHDRAWAL_POLICY` 행에 있는 첫 번째 콘텐츠 영역, 영구 탈퇴 목록은 두 번째 콘텐츠 영역에서 조회합니다. 콘텐츠가 없거나 조회 및 JSON 검증에 실패하면 화면에 포함된 현재 기본 문구를 표시합니다. 세부 저장 및 조회 기준은 [사용자 안내 팝업 콘텐츠 정책](popup-content-policy.md)을 따릅니다.

## 계정 비활성화

- 처리 유형: `SOFT`
- 회원 상태: `비활성화`
- 관리자 이용 정지가 적용된 `이용정지` 회원은 정지를 우회할 수 있으므로 비활성화를 신청할 수 없습니다.
- 같은 Kakao 계정으로 재로그인하면 기존 회원 계정을 `활성` 상태로 다시 활성화합니다.
- 회원 원본 정보와 로그인 이력은 유지합니다.
- 사용자가 선택한 표시 언어는 계정 설정과 함께 유지하며, 같은 계정으로 복귀하면 별도 초기화 없이 다시 적용합니다.
- 설치 권장 알럿 확인 일시는 사용자 기본정보와 함께 유지하되 비활성화 기간에는 알럿을 표시하거나 확인 일시를 변경하지 않습니다.
- 같은 계정으로 재로그인해 활성 상태로 복귀하면 유지한 확인 일시를 사용하며, 확인 이력이 있으면 알럿을 다시 표시하지 않습니다.
- 작성한 독후감은 모두 비공개로 전환합니다.
- 독후감의 작성 언어와 생성된 번역문은 독후감 원문과 함께 유지하며, 같은 계정으로 복귀하면 별도 복원 없이 다시 사용할 수 있습니다.
- 작성한 댓글은 삭제된 댓글 상태로 전환합니다.
- 댓글에 등록한 좋아요는 삭제하며 계정 재활성화 시 자동 복원하지 않습니다.
- 좋아요 수와 좋아요 사용자 목록은 정상 이용 중인 회원만 포함하므로 비활성화 기간에는 보존된 독후감·사진 좋아요도 다른 회원 화면의 수와 목록에서 제외합니다.
- 같은 계정이 정상 이용 상태로 복귀하면 보존된 독후감·사진 좋아요는 다시 집계하며, 비활성화 과정에서 삭제한 댓글 좋아요는 복원하지 않습니다.
- 댓글 수정·삭제 메뉴와 API는 `활성` 상태에서 본인이 작성한 미삭제 댓글에만 제공합니다.
- `비활성화` 상태에서는 본인 댓글 수정·삭제 메뉴를 표시하지 않으며 직접 API를 호출해도 처리하지 않습니다.
- 수신 알림은 삭제 상태로 전환합니다.
- 비활성화 전에 다른 회원에게 발송된 댓글 좋아요 알림은 수신자의 알림 기록으로 유지하며, 발신 회원이 복귀해도 새로 생성하거나 복원하지 않습니다.
- 댓글 좋아요 알림은 `활성` 회원 간 신규 좋아요에만 생성하고 기존 알림의 삭제·보존·복원에는 현재 계정 수명주기 정책을 그대로 적용합니다.
- 브라우저 푸시 구독은 비활성화합니다.
- `비활성화` 전환 즉시 모든 기기의 로그인 세션을 폐기하고 Access Token의 `sid`도 더 이상 인증에 사용할 수 없게 합니다.
- `비활성화(계정 비활성화)` 전환 후에도 `사용자 팔로우 관계(팔로우 관계)`는 유지하고 팔로우·팔로워 목록에 노출합니다.
- 피드의 사용자 검색은 활성 회원만 제공하므로 비활성화 기간에는 보존된 닉네임과 팔로우 관계가 있어도 검색 결과에서 제외합니다. 같은 계정이 정상 이용 상태로 복귀하면 보존된 닉네임과 관계를 기준으로 다시 검색할 수 있습니다.
- `비활성화(계정 비활성화)` 전환 후에도 사용자가 설정한 개인 차단 관계와 다른 사용자가 해당 사용자를 차단한 관계를 모두 유지합니다. 같은 계정이 복귀하면 별도 복원 없이 기존 차단 관계를 그대로 적용합니다.
- 개인 차단으로 이미 만료된 당사자 간 모임 초대와 취소된 가입 신청은 계정 비활성화 복귀로 복원하지 않습니다.
- 공개 독후감의 팔로우 작성자 우선 정렬에는 `활성` 작성자의 공개 독후감만 사용하므로 `비활성화` 상태에서는 유지된 팔로우 관계가 있더라도 정렬 대상에서 제외합니다.
- 다른 사용자가 목록의 `비활성화(계정 비활성화)` 회원을 눌러 소셜 프로필에 진입하면 `사용자 계정 상태(회원 상태)`를 알림으로 표시하고, 확인하면 이전 화면으로 이동합니다.
- 프로필과 배경 이미지의 물리 파일 및 업로드 파일 정보 메타정보는 유지하고 다른 사용자의 접근만 제한합니다.
- 비활성화 기간에는 보존된 프로필·배경사진의 공개 반응 화면과 좋아요·댓글 API 접근을 제한합니다.
- 같은 Kakao 계정으로 재로그인해 `활성` 상태로 복귀하면 유지한 프로필과 배경 이미지를 다시 노출합니다.
- 비활성화 과정에서 변경된 독후감 공개 상태, 댓글, 알림, 푸시 구독은 계정 재활성화 시 자동 복원하지 않습니다.
- 독후감별 좋아요·댓글 알림 설정은 독후감과 함께 보존하되 계정 제한 기간에는 적용할 신규 활동 알림을 만들지 않습니다. 복귀 후 사용자가 독후감을 직접 다시 공개하면 비활성화 전 설정값을 그대로 적용하며 자동으로 켜거나 끄지 않습니다.
- 재로그인으로 계정을 활성화해도 비활성화한 푸시 구독은 자동 복원하지 않으며 사용자가 다시 명시적으로 켜야 합니다.
- 계정이 다시 활성화된 로그인에는 “다시 돌아와서 반가워요” 팝업을 표시하고 자동 복원되지 않는 항목을 다시 안내합니다.
- 일반 로그인에는 비활성화 계정 복귀 팝업을 표시하지 않습니다.
- 계정 비활성화가 완료되면 저장하지 않은 프로필 및 배경 이미지 임시 선택본은 즉시 물리 삭제하며, 재로그인으로 계정을 복구해도 복원하지 않습니다.
- 비활성화 회원이 남긴 다음 도서 추천과 투표 기록은 보존하되 후보별 집계와 화면 표시에서 제외합니다. 같은 계정이 활성 상태로 복귀하면 기존 기록을 다시 집계에 포함합니다.

## 로컬 개발용 간편 로그인

- 로컬 개발용 간편 로그인은 `loc` 프로필이 활성화되고 운영 프로필은 비활성화된 경우에만 제공하며 운영 프로필에는 로그인 처리 객체를 등록하지 않습니다.
- 회원 번호는 URL로 입력받지만 권한과 현재 회원 상태는 서버가 사용자 원본에서 다시 조회합니다.
- 활성 회원만 로그인할 수 있으며 비활성화, 영구 탈퇴 대기 및 이용정지 회원은 모두 인증 실패로 처리합니다.
- 로컬 개발용 간편 로그인은 비활성화 계정을 재활성화하거나 영구 탈퇴를 취소하지 않으며 회원 상태와 탈퇴 관련 일시를 변경하지 않습니다.
- 제한된 계정에는 인증 Cookie와 Redis 로그인 세션을 발급하지 않습니다. 물리 삭제된 회원도 사용자 원본을 조회할 수 없으므로 로그인할 수 없습니다.
- 활성 회원으로 로그인한 뒤에는 해당 회원의 현재 공개 범위, 보존 데이터, 알림 설정, 푸시 구독 및 소셜 관계를 그대로 사용하며 추가 삭제나 복원을 수행하지 않습니다.
- localhost와 설정된 Tailnet 주소에서 같은 기능을 사용할 수 있으며 로그인 완료 후 요청을 시작한 개발 프런트엔드로만 이동합니다.

## 영구 탈퇴

- 처리 유형: `HARD`
- 회원 상태: 영구 탈퇴 대기
- 운영 환경은 신청 직후 삭제하지 않고 기본 30일의 유예기간을 둡니다.
- 유예기간에는 영구 삭제 예정일을 사용자에게 표시합니다.
- 유예기간이 끝나기 전에는 영구 탈퇴를 취소할 수 있습니다.
- 유예기간에는 설치 권장 알럿 확인 일시를 사용자 기본정보와 함께 유지하되 알럿을 표시하거나 확인 일시를 변경하지 않습니다.
- 영구 탈퇴를 취소하면 유지한 확인 일시를 별도 복원 없이 다시 사용합니다.
- 영구 탈퇴 대기 전환 즉시 모든 기기 로그인 세션과 푸시 구독을 비활성화합니다. 취소하려면 같은 Kakao 계정으로 다시 로그인해 삭제 대기 전용 화면에서 명시적으로 취소해야 합니다.
- 관리자 이용 정지 중인 회원은 정지 해제 또는 기간 만료 전까지 영구 탈퇴를 신청할 수 없습니다.
- 취소하면 유효한 관리자 이용 정지가 남아 있을 때는 `이용정지`, 남아 있지 않을 때는 `활성`로 복구하고 탈퇴일과 삭제 예정일을 제거합니다.
- 영구 탈퇴 대기 중에도 사용자가 선택한 표시 언어를 유지하며, 탈퇴를 취소하면 보존된 언어를 그대로 적용합니다.
- 유예기간 동안에도 독후감 비공개, 댓글 삭제 상태, 알림 삭제 상태, 푸시 비활성화 정책을 적용합니다.
- 영구 탈퇴 대기 유예기간에는 독후감별 좋아요·댓글 알림 설정을 보존하지만 신규 독후감 활동 알림은 중지합니다. 탈퇴를 취소하고 사용자가 독후감을 직접 다시 공개하면 보존된 설정을 적용합니다.
- 영구 탈퇴 대기 유예기간에는 유지된 팔로우 관계가 있더라도 비공개 처리된 독후감을 공개 목록과 팔로우 작성자 우선 정렬에 사용하지 않습니다.
- `영구 탈퇴 대기(영구 탈퇴 유예)` 동안 `사용자 팔로우 관계(팔로우 관계)`를 유지하고 팔로우·팔로워 목록에 노출합니다. 목록에서 해당 회원을 눌러 소셜 프로필에 진입하면 `사용자 계정 상태(회원 상태)`를 알림으로 표시하고, 확인하면 이전 화면으로 이동합니다.
- 피드의 사용자 검색은 활성 회원만 제공하므로 영구 탈퇴 대기 기간에는 보존된 닉네임과 팔로우 관계가 있어도 검색 결과에서 제외합니다. 탈퇴 취소 뒤 정상 이용 상태로 복귀한 경우에만 보존된 닉네임과 관계를 기준으로 다시 검색할 수 있습니다.
- 영구 탈퇴 대기 유예기간에는 사용자가 설정한 개인 차단 관계와 다른 사용자가 해당 사용자를 차단한 관계를 모두 유지합니다. 탈퇴를 취소하면 별도 복원 없이 기존 차단 관계를 그대로 적용합니다.
- 개인 차단으로 이미 만료된 당사자 간 모임 초대와 취소된 가입 신청은 영구 탈퇴 취소로 복원하지 않습니다.

## 2차 회원 탈퇴정책

이 절은 2026년 8월 13일부터 적용한 2차 회원 탈퇴정책입니다. 고객문의 기능은 확장하지 않고 정지 회원의 영구탈퇴와 탈퇴 후 동일 Kakao 계정의 제재 판정만 처리합니다.

- `이용정지` 회원도 일반 영구탈퇴와 동일하게 30일 유예가 적용되는 영구탈퇴를 신청할 수 있게 변경합니다.
- 영구탈퇴를 신청해 영구 탈퇴 대기로 전환되어도 기존 이용정지 이력과 유효한 제재는 유지합니다.
- 유예기간 중 관리자가 제재를 해제해도 회원 상태는 영구 탈퇴 대기로 유지하고, 사용자가 영구탈퇴를 취소하면 남은 유효 제재 여부에 따라 `이용정지` 또는 `활성`로 복구합니다.
- 유예기간 종료 후 회원 원본을 물리 삭제하더라도 회원 계정 처리 이력의 탈퇴 시 보존하는 사용자 식별값 해시의 Kakao 식별값 해시와 탈퇴 당시 사용자 번호를 유지하고, 해당 회원번호의 회원 이용 정지 이력 이용정지 이력을 보존합니다.
- 로그인 시 Kakao 식별값을 현재 탈퇴 처리와 같은 SHA-256 방식으로 해시하여 회원 계정 처리 이력의 탈퇴 시 보존하는 사용자 식별값 해시에서 기존 사용자 번호를 찾고, 해당 회원번호에 활성 제재가 남아 있으면 신규 가입을 차단합니다.
- 같은 Kakao 식별값에 여러 과거 사용자 번호가 연결되어 있으면 그중 하나라도 유효한 제재가 남아 있는 동안 신규 가입을 차단합니다.
- 기간 정지는 종료 예정 일시가 현재보다 미래일 때만 유효하며, 무기한 정지는 관리자 해제 전까지 유효합니다.
- 관리자는 `현 사용자 관리 > 삭제회원 제재` 화면(`/sadari/adm/user/deleted-suspensions`)에서 물리 삭제된 회원 원본을 복구하지 않고 과거 사용자 번호에 남은 제재만 해제할 수 있습니다.
- 삭제 회원 제재 화면과 API에는 탈퇴 시 보존하는 사용자 식별값 해시를 제공하지 않으며 과거 사용자 번호, 제재번호, 사유, 기간과 감사정보만 제공합니다.
- 삭제 회원 제재 해제에는 관리자 내부 메모가 필수이며 회원 이용 정지 이력에 해제 관리자, 해제일시와 해제 메모를 기록합니다.
- 제재 해제 뒤 같은 Kakao 계정으로 가입하면 새 사용자 번호를 발급하고 탈퇴 전 프로필, 활동, 고객문의 및 답변을 새 계정에 연결하거나 복원하지 않습니다.
- 회원 계정 처리 이력의 탈퇴 시 보존하는 사용자 식별값 해시, 사용자 번호 복합 인덱스로 탈퇴 식별값과 과거 회원번호 연결 조회를 지원합니다.
- 회원 계정 처리 이력과 회원 이용 정지 이력은 현재 별도 만료기간을 두지 않는 감사 이력으로 보존합니다.

## 신고 데이터 처리

- `비활성화` 회원이 접수한 기존 신고는 유지하고 관리자만 조회할 수 있으며 신규 신고는 허용하지 않습니다.
- `비활성화` 또는 영구 탈퇴 대기 회원의 프로필과 콘텐츠는 일반 화면에서 숨기고 사용자 계정·독후감·댓글·프로필 사진·배경사진·한줄소개를 새 신고 대상으로 조회하지 않습니다.
- 같은 계정이 `활성`로 복귀하면 보존된 신고 이력을 기준으로 동일 대상 버전 재신고를 계속 차단합니다.
- 영구 탈퇴 대기 유예기간에도 기존 신고를 유지하고 영구 탈퇴 취소 시 별도 복원 없이 같은 신고 이력과 중복 신고 제한을 유지합니다.
- 회원 원본을 물리 삭제하면 신고 이력의 사용자 번호를 `NULL`로 변경하여 신고자를 익명화하고 신고 기록은 운영 이력으로 유지합니다. 이후 생성된 새 계정은 익명화된 과거 신고와 연결하지 않으므로 신고 가능한 대상이면 새 계정 기준으로 신고할 수 있습니다.
- 신고 대상 사용자 또는 콘텐츠가 삭제되어도 신고 이력의 대상 유형과 대상 번호는 유지합니다.
- 신고 접수 서버가 원본에서 확정한 대상 소유 사용자 번호를 신고 이력의 신고 대상 소유 사용자 번호에 저장합니다. 대상자의 `비활성화` 또는 영구 탈퇴 대기 상태에서도 이 연결과 신고 이력을 유지합니다.
- 관리자 `현 사용자 관리 > 현 사용자 상세`는 `활성`, `비활성화`, 영구 탈퇴 대기 회원이 받은 신고의 누적 횟수와 전체 이력을 신고 대상 소유 사용자 번호 기준으로 제공합니다. 계정 비활성화 복귀나 영구 탈퇴 취소 후에도 같은 이력을 별도 복원 없이 제공합니다.
- 대상자 회원 원본이 물리 삭제되면 신고 대상 소유 사용자 번호를 `NULL`로 변경합니다. 물리 삭제 뒤에는 현 사용자 상세가 존재하지 않으며, 신고 대상 스냅샷과 처리 이력은 관리자 신고 관리에서만 익명 운영 이력으로 유지합니다.
- 신고 접수 시 대상 유형별 실제 원문을 신고 이력의 신고 대상 내용 스냅샷에 관리자 전용 스냅샷으로 저장하고 실제 원문 또는 프로필·배경 이미지 바이트의 SHA-256을 신고 대상 버전 SHA-256 해시에 저장하며 일반 사용자에게 공개하지 않습니다.
- 프로필·배경사진 신고는 실제 이미지 원본을 관리자 전용 신고 이미지 증거에 저장합니다. 대상자나 신고자가 `비활성화`, 영구 탈퇴 대기로 전환되어도 미처리 증거와 최종 처리 후 180일 보존기간을 그대로 적용합니다.
- 회원 원본 물리 삭제 시 관리자 전용 이미지 증거의 신고 대상 소유 사용자 번호를 `NULL`로 익명화하되 이미지 증거는 만료일까지 유지합니다. 계정 복귀 또는 영구 탈퇴 취소는 관리자 공개 범위와 만료일을 변경하거나 이미 삭제된 증거를 복원하지 않습니다.
- 연결 신고가 모두 최종 처리된 뒤 마지막 처리일부터 180일이 지나면 이미지 증거 행을 물리 삭제하고 신고의 신고 증거 번호 연결만 `NULL`로 변경합니다. 텍스트 스냅샷, 대상 해시와 자동 조치 이력은 운영 이력으로 계속 유지합니다.
- 신고 대상 내용 스냅샷은 신고 대상 원본의 수정·삭제와 신고자 또는 대상자의 `비활성화`, 영구 탈퇴 대기 및 물리 삭제 뒤에도 신고 이력과 함께 유지합니다.
- 계정 비활성화 복귀 또는 영구 탈퇴 취소 시 보존한 신고 대상 내용 스냅샷을 현재 원본으로 재동기화하거나 복원하지 않고 접수 시점 값으로 유지합니다.
- 관리자는 `신고 관리 > 신고 상세`와 `현 사용자 관리 > 현 사용자 상세`에서 `활성`, `비활성화`, 영구 탈퇴 대기 사용자의 프로필·배경 이미지를 기본 이미지 상태로 변경하고 자기소개를 `NULL` 처리할 수 있습니다.
- 관리자는 신고 대상 독후감을 연결 댓글·답글·좋아요와 함께 완전 삭제하고, 댓글 또는 답글은 원본 행을 보존한 채 `삭제 여부='Y'`로 변경하며, 모임 소개는 `NULL` 처리할 수 있습니다.
- 관리자 신고 조치로 삭제하거나 비공개 상태로 변경된 프로필 정보와 콘텐츠는 계정 비활성화 복귀 또는 영구 탈퇴 취소 시 자동 복원하지 않습니다.
- 반려를 제외한 같은 대상 버전 신고가 로컬 1건 또는 운영 5건 누적되면 독후감은 비공개로 전환하고 댓글은 `삭제 여부='Y'`, 프로필·배경사진은 각각 기본 이미지 상태, 한줄소개는 `NULL`로 자동 변경합니다. 자동 조치는 기존 신고 대상이 이후 `비활성화`, 영구 탈퇴 대기로 바뀌어도 적용하며 계정 복귀 또는 영구 탈퇴 취소 시 복원하지 않습니다. 독후감 완전 삭제는 관리자만 실행합니다.
- 자동 조치 결과는 자동 조치 이력에 유지하며 대상 회원이 물리 삭제되면 신고 대상 소유 사용자 번호를 `NULL`로 익명화합니다. 물리 삭제된 대상에는 신규 자동 조치를 실행하지 않습니다.
- 신고 조치 결과 확인 대상은 신고가 조치 완료된 시점에 보존 대상 신고자와 피신고자별로 생성합니다. 이용정지 회원의 결과는 보존하고 정지 해제 후 전용 팝업으로 확인합니다.
- 비활성화 또는 영구 탈퇴 대기로 전환하면 확인 여부와 관계없이 해당 회원의 신고 조치 결과를 모두 삭제합니다. 해당 상태에서는 새 결과를 만들지 않으며 재활성화 또는 탈퇴 취소 후에도 복원하지 않습니다.
- 신고 조치 결과 팝업은 알림센터, 알림 템플릿 및 푸시 구독을 생성하거나 변경하지 않습니다.
- 신고 데이터 처리는 알림, 푸시 구독, 팔로우, 좋아요 및 기타 소셜 관계의 삭제·보존·복원 범위를 변경하지 않습니다.
- 관리자 신고 상세의 자동 조치 진행 정보와 결과 이력은 `활성`, `비활성화`, 영구 탈퇴 대기 상태에서 유지하며, 물리 삭제 뒤에는 피신고자 회원번호를 익명화한 기존 결과만 대상 유형과 번호 기준으로 제공합니다.
- 세부 신고 대상과 처리 상태는 [신고 접수 및 처리 정책](abuse-report-policy.md)을 따릅니다.

## 고객문의 데이터 처리

- `활성`와 `이용정지` 회원은 1차 고객문의 기능을 이용할 수 있습니다.
- `이용정지` 회원은 현재 정지에 연결되는 이용정지 이의제기 문의만 접수할 수 있고, 정지 화면에서 현재 정지 이후 접수한 최신 문의를 다시 조회할 수 있습니다.
- `비활성화`과 영구 탈퇴 대기 회원은 기존 문의를 유지하되 1차 고객문의 화면과 API에 접근할 수 없습니다.
- `비활성화` 회원이 같은 Kakao 계정으로 재로그인해 기존 계정이 `활성`로 복귀하면 유지된 본인 문의와 답변을 다시 조회할 수 있습니다.
- 회원 원본을 물리 삭제하면 고객문의 접수와 처리 상태의 사용자 번호를 `NULL`로 변경해 작성자를 비식별화하고 문의와 답변은 관리자 운영 이력으로 보존합니다.
- 물리 삭제 뒤 새로 생성된 회원 계정에는 탈퇴 전 문의와 답변을 연결하거나 복원하지 않습니다.
- 정지 회원의 영구탈퇴 허용, 활성 제재가 연결된 Kakao 계정의 재가입 차단과 관리자 해제는 이 문서의 2차 회원 탈퇴정책에 따라 처리합니다.
- 세부 기준은 [고객문의 및 관리자 답변 정책](customer-inquiry-policy.md)을 따릅니다.

## 독서 타이머 및 출석 데이터 처리

- `비활성화`과 영구 탈퇴 대기 전환 시 진행 중이거나 일시정지된 독서 타이머를 즉시 완료 처리하고 이후 타이머 화면과 API 접근을 중지합니다.
- 계정 상태 전환으로 타이머를 완료할 때 아직 발송되지 않은 목표시간 예약 목표시간 알림 예정 일시를 제거하며 복귀 또는 영구 탈퇴 취소 시 자동 복원하지 않습니다.
- 목표시간으로 이미 `완료(COMPLETED)`됐지만 알림 저장을 재시도 중인 세션도 `계정 비활성화(비활성화)` 또는 `영구 탈퇴 대기(영구 탈퇴 대기)` 전환 시 예약 목표시간 알림 예정 일시를 제거하고 이후 알림을 발송하지 않습니다.
- `비활성화`과 영구 탈퇴 대기 상태에서는 일반 네비게이션의 타이머 실행 표시와 홈 타이머 플레이어를 제공하지 않으며, 계정 복귀 후 새 활성 타이머가 시작된 경우에만 다시 표시합니다.
- 계정 제한 전까지 확정된 세션 상세와 날짜별 누적 독서 시간은 유지합니다.
- 계정 비활성화 복귀 또는 영구 탈퇴 취소 시 보존된 타이머 기록과 출석 이력을 다시 제공합니다.
- 도서별 누적 독서 시간 목록은 보존 중인 완료 세션 상세를 기준으로 계산하므로 `비활성화`과 영구 탈퇴 대기 상태에서는 페이지 조회 API까지 차단해 숨기고, 계정 복귀 또는 영구 탈퇴 취소 시 보존된 기록 범위에서 20권 단위로 다시 제공합니다.
- 도서별 누적 독서 시간의 독후감 이동 링크는 계정 제한 중 함께 숨기며, 계정 복귀 또는 영구 탈퇴 취소 뒤 보존된 본인 독후감 연결만 다시 제공합니다. 연결 독후감의 접근·공개·보존·삭제는 기존 독후감 정책을 따르며 별도 공개 또는 복원 동작을 추가하지 않습니다.
- 완료된 세션 상세는 종료일 기준 1년 동안 보존하며 날짜별 누적값은 회원 원본이 물리 삭제될 때까지 유지합니다.
- 목표시간 알림 목표 독서 시간 초, 알림 예정 일시 목표시간 알림 예정 일시, 발송 일시 알림 발송 일시는 해당 타이머 세션 상세의 보존·삭제 범위를 그대로 따릅니다.
- 상태 전환 전에 이미 저장된 독서 타이머 기간 초과 알림은 받은 알림의 기존 삭제·미복원 정책을 따릅니다.
- 유예기간이 끝나 회원이 물리 삭제되면 독서 타이머 세션과 일별 독서 시간 집계의 회원 데이터를 모두 삭제하고 복구하지 않습니다.
- 회원 원본 물리 삭제 뒤에는 도서별 누적 독서 시간도 별도 집계나 스냅샷으로 보존하지 않으며 복구하지 않습니다.
- 마이페이지 독서 통계는 `활성` 상태의 본인에게 제공하며, 공개를 허용한 경우에만 다른 사용자의 프로필에도 제공합니다. `비활성화`과 영구 탈퇴 대기 상태에서는 본인 화면과 공개 프로필 모두에서 통계를 제공하지 않습니다.
- `비활성화` 또는 영구 탈퇴 대기 전환 시 본인과 공개 프로필의 모든 연도 독서 통계를 숨기고 독서 통계 공개 설정을 비공개로 변경합니다. 사용자 설정 데이터가 없으면 공개 설정을 복원하지 않도록 비공개 초기값으로 생성합니다.
- 계정 복귀 또는 영구 탈퇴 취소 후에도 독서 통계 공개 여부를 자동 복원하지 않으며 회원이 다시 공개로 설정해야 합니다.
- 계정 제한 중에는 연속 독서 기록, 올해 가장 오래 읽은 책, 별점 분포와 작년 비교를 포함한 모든 독서 통계를 숨기며, 계정 복귀 후에는 보존된 일별 독서 시간 집계, 보존기간 안의 독서 타이머 세션과 독후감로 해당 통계를 다시 계산합니다. 물리 삭제 뒤에는 별도 통계 이력으로 복원하지 않습니다.
- 유예기간이 끝나 회원을 물리 삭제할 때 회원별 서비스 설정의 회원 설정 행도 회원 원본보다 먼저 삭제하고 복구하지 않습니다.
- 독서 통계를 위한 별도 개인 스냅샷은 저장하지 않으며 원본 데이터의 보존과 삭제 범위를 그대로 따릅니다.
- 연결된 독후감이 삭제되면 타이머 세션의 독후감 연결만 제거하고 확정 독서 시간은 유지합니다.
- 타이머 데이터 처리는 독후감 공개 여부, 댓글, 알림, 푸시 구독, 좋아요와 팔로우 관계의 기존 삭제·보존·복원 범위를 변경하지 않습니다.
- 타이머의 현재 읽는 책 팝업에서 도서 검색과 목표 독서기간을 거쳐 생성한 `읽는 중` 독후감도 일반 독후감의 접근·비공개·보존·삭제·복귀 범위를 그대로 적용합니다.
- `비활성화`과 영구 탈퇴 대기 상태에서는 타이머에서 시작한 도서 검색과 후속 독후감 등록을 차단하며, 제한 전에 저장이 완료된 `읽는 중` 독후감만 기존 독후감 정책에 따라 보존합니다.
- 계정 제한 전에 검색 화면 또는 타이머 전용 목표일 팝업에서 확정하지 않은 도서와 목표기간은 서버에 저장하지 않고 복귀 또는 영구 탈퇴 취소 뒤 자동 복원하지 않습니다.
- 타이머 경로의 `읽는 중` 독후감 등록은 별도 알림을 만들거나 댓글, 푸시 구독, 좋아요, 팔로우 및 기타 소셜 관계를 변경하지 않습니다.

세부 출석과 측정 기준은 [독서 타이머 및 주간 출석 정책](reading-timer-attendance-policy.md)을 따릅니다.
마이페이지 통계의 연도 조회와 지연 조회 기준은 [마이페이지 독서 통계 정책](my-page-reading-statistics-policy.md)을 따릅니다.

## 사용자 설정 데이터 처리

다음 기준은 사용자 설정 기능과 계정 상태 수명주기에 적용하는 현재 정책입니다.

- `비활성화` 또는 영구 탈퇴 대기 상태에서는 일반 설정 화면에 접근할 수 없습니다.
- 상태 전환 시 독서 통계, 독서 목표와 사진 변경 활동의 공개 설정을 비공개로 변경합니다.
- 비공개로 변경한 공개 설정은 계정 복귀 또는 영구 탈퇴 취소 시 자동 복원하지 않으며 사용자가 직접 다시 공개해야 합니다.
- 독서 목표 원본은 유예기간 동안 보존하지만 제한 상태에서는 본인 및 다른 사용자에게 제공하지 않습니다.
- 좋아요, 댓글·답글, 팔로우, 선택 가능한 독서모임 활동 및 독서 종료일 리마인더의 수신 선호는 보존합니다.

## 독서모임장 연계 예정 정책

이 절은 독서 모임 설계에 확정된 연계 기준입니다. 1차 개발에서는 영구탈퇴 물리 삭제에 한해 가입 순서 기반 즉시 승계를 프로시저에 반영하고, 일반적인 부재 사유의 투표 선거는 후속 개발 범위로 둡니다.

- 모임장이 복구 불가능한 영구 이용 제한을 받으면 관리자가 비가역성을 확인한 뒤 같은 선거 절차를 시작합니다.

- `비활성화`, 기간이 정해진 이용 정지, 해제 가능성이 남은 무기한 이용 정지 및 영구 탈퇴 대기만으로는 확정 부재로 판정하지 않습니다.
- 최근 로그인·게시·채팅 활동이 없다는 사실만으로는 모임장 선거를 시작하지 않습니다.
- 확정 부재 사유, 근거, 확정자와 일시는 모임장 선거 원본에 저장합니다. 선거에 따른 권한 변경만을 위한 별도 감사 이력은 남기지 않습니다.

- 영구 탈퇴를 취소하면 모임원 자격은 복원하되 비활성화된 푸시 구독과 개인 독후감 공개 설정은 자동 복원하지 않습니다.
- 물리 삭제 뒤에는 소유 모임을 다시 찾을 수 없으므로 사용자 계정과 프로필 삭제 직전에 모임별 확정 부재 이벤트와 모임장 선거를 멱등하게 기록합니다.
- 모임별 부재 이벤트와 선거 생성이 모두 성공하면 선거 완료를 기다리지 않고 예정된 계정 물리 삭제를 진행합니다. 한 모임이라도 기록에 실패하면 계정 삭제 전체를 재시도 대상으로 남깁니다.
- 선거는 시작 시점의 활성 모임원 명부로 24시간 동안 정족수 없이 비밀투표를 진행하고, 유효표 최다 득표자를 다음 모임장으로 선출합니다.

- 선거 데이터는 탈퇴한 기존 모임장 번호를 원본 회원 FK 없이 보존합니다.

- `비활성화` 또는 영구 탈퇴 대기 회원은 이전 독서 기록 화면과 회차별 목표 결과 조회 API를 이용할 수 없습니다. 계정이 `활성`로 복귀하면 공개 중인 활성 모임의 이전 독서 기록 요약을 조회할 수 있고, 활성 모임원 관계도 유지된 경우 가입 시점과 관계없이 해당 모임의 모든 종료 회차와 회차별 목표 결과를 다시 조회할 수 있습니다. 제한 전 비식별 처리된 개인 참여·달성 연결은 복원하지 않습니다.

#### 모임 자진 탈퇴

- 활성 계정의 활성 일반 모임원만 자진 탈퇴할 수 있으며 모임장은 승계 또는 모임 삭제를 먼저 완료해야 합니다.

- 회원 관계에는 탈퇴 사실과 처리 일시만 보존하고 재가입을 차단하지 않습니다. 공개 모임 재가입은 기존 가입 방식과 정원 및 승인 정책을 다시 적용합니다.
- 계정 비활성화 또는 영구 탈퇴 대기 상태에서는 자진 탈퇴 화면과 API에 접근할 수 없고, 해당 계정 상태 전환만으로 모임 자진 탈퇴를 자동 실행하지 않습니다.
- 자진 탈퇴 후에는 해당 모임 채팅을 새로 조회하거나 작성할 수 없지만, 이미 작성한 채팅 본문과 작성자 연결은 운영 기록으로 유지합니다.
- 비활성화 복귀 또는 영구 탈퇴 취소 시에는 계정 제한 동안 모임 편집·삭제가 실행되지 않았으므로 기존 모임 데이터를 별도로 복원하지 않고 유지된 모임원 자격과 운영 상태를 기준으로 접근을 재개합니다.
- 비활성화 또는 삭제 대기 회원의 개인 독후감과 채팅 기록은 기존 보존 정책을 따르되 모임 회차와 독후감 연결은 제거하고 작성자 프로필 접근을 제한합니다.
- 물리 삭제 시 회원 관심분야, 해당 회원의 가입 신청 행과 모임 회원 및 초대 예약석 회원·초대 행을 외래키 연쇄 삭제로 함께 제거합니다. 별도 초대 이력은 존재하지 않으며 승인·거절된 신청 답변은 신청 처리 시점에 이미 삭제되어 있어야 합니다.
- 물리 삭제 뒤에도 운영상 필요한 모임 퇴장·제한 이력은 보존하되 삭제 회원의 식별정보를 비식별화하고 새 계정에 연결하거나 복원하지 않습니다.
- 물리 삭제된 계정의 모임원 프로필과 회원 관계는 복구하지 않습니다.
- 물리 삭제 대상이 모임장이면 회원 삭제 전에 해당 모임의 `활성` 회원 중 회원 가입 일시, 사용자 번호가 가장 빠르고 계정 상태가 `활성`인 회원에게 즉시 승계합니다. 승계 후보가 없으면 모임과 모든 종속 데이터를 물리 삭제합니다.
- 물리 삭제 시 회원의 독후감을 삭제하고 모임 화면에는 삭제된 독후감으로 표시합니다.
- 물리 삭제 시 채팅 본문은 유지하고 작성자 식별 연결만 제거해 `탈퇴한 사용자`의 메시지로 표시합니다. 강제 퇴장 이력도 대상자와 처리자 식별 연결만 제거하고 사유·처리일·제한 해제일은 유지합니다.
- `비활성화` 또는 영구 탈퇴 대기 중에는 모임 채팅 조회·전송과 새 채팅 알림을 모두 중지합니다. 계정이 `활성`로 복귀하고 활성 모임원 관계가 유지되면 기존 채팅 알림 설정값을 그대로 적용합니다.
- `비활성화`, 영구 탈퇴 대기, 자진 탈퇴 또는 강제 퇴장 상태에서는 기존 채팅의 안 읽은 인원 수에서 즉시 제외합니다. 계정 제한이 해제되고 활성 모임원 관계가 유지되면 보존한 마지막 읽은 위치를 다시 사용하며, 탈퇴 후 재가입한 회원은 새 가입일 이전 메시지의 안 읽은 수에 포함하지 않습니다.
- 계정 제한 전환 시 제거한 회차 참여자의 식별값과 독후감 번호 연결은 물리 삭제 시에도 복원하지 않습니다. 비식별 참여 흔적은 과거 회차 보존 데이터로 유지할 수 있지만 현재 목표 달성 인원과 참여 인원 집계에서는 제외하며 탈퇴한 달성자의 이름을 목록에 표시하지 않습니다.

상세 기준은 [독서 모임 정책 결정 항목](reading-club-policy-decisions.md)과 [독서 모임 상세 기획 및 기술 설계](../architecture/reading-club-design.md)를 함께 따릅니다.

## 로컬 영구 탈퇴 테스트

- `loc` 프로필은 `withdrawal.hard-delete-wait-days`를 `0`으로 설정해 영구 탈퇴 요청 시 삭제 예정일을 즉시 도래시킵니다.
- `withdrawal.hard-delete-test-enabled`가 `true`이면 로컬 전용 스케줄러가 10초마다 영구 삭제 대상을 처리합니다.
- 로컬 전용 스케줄러는 `loc` 프로필에서만 생성되며 운영 프로필에서는 활성화할 수 없습니다.
- 테스트 설정은 특정 회원만 구분하지 않으므로 연결된 DB에서 삭제 예정일이 지난 모든 회원을 대상으로 합니다.
- 공용 개발 DB에서 테스트할 때는 다른 사용자가 영구 탈퇴 대기 상태인지 확인한 뒤 실행해야 합니다.

## 외부 연동 실패

- Kakao 연결 해제가 실패하면 회원 상태를 변경하지 않습니다.
- 탈퇴 이력은 외부 계정 연결 해제 대기 상태로 기록하고 제한된 길이의 오류 내용을 저장합니다.
- 외부 연결 해제에 성공해야 계정 비활성화 또는 영구 삭제 대기 상태를 적용합니다.

## 서비스 간 회원 상태 동기화

- 비활성화와 영구 탈퇴는 사용자 서버가 처리하므로 해당 서버의 Redis 상태를 즉시 함께 변경합니다.
- 관리자가 정지·해제한 회원 상태는 DB Outbox를 통해 사용자 서버의 Redis에 최대 5분 안에 반영합니다.
- Outbox에는 이벤트 번호·유형·내부 회원번호·등록일시만 임시 저장하고 성공 처리 후 삭제합니다.
- 회원 원본이 이미 영구 삭제된 이벤트를 처리하면 사용자 서버의 남은 로그인 정보를 제거한 뒤 이벤트를 삭제합니다.
- 상태 동기화를 위해 별도 푸시알림을 발송하지 않습니다.

## 탈퇴 상태값

| 상태 | 의미 |
| --- | --- |
| 완료 | 계정 비활성화 적용 완료 |
| 외부 계정 연결 해제 대기 | Kakao 연결 해제 실패로 재처리 필요 |

## 관리자 계정 처리 이력 조회

- 관리자 `현 사용자 관리` 상세에서는 사용자 계정과 프로필 원본 행이 존재하는 회원의 회원 계정 처리 이력만 읽기 전용으로 확인합니다.
- 관리자 `현 사용자 관리` 상세와 `신고 관리` 상세에서는 `활성`, `비활성화`, 영구 탈퇴 대기 회원에게 보존된 프로필 및 배경 이미지가 있을 때만 보기 버튼과 삭제 권한 기반 기본 이미지 변경 버튼을 제공하고 관리자 인증 모달에서 이미지를 확인합니다. 신고 관리 상세는 모든 신고 유형에서 신고 대상 소유 사용자 번호로 연결된 피신고자의 현재 이미지 정보를 사용합니다.
- 이미지 버튼은 목록 그리드의 열을 늘리지 않고 상세 정보의 기존 셀 또는 기존 열 구조를 유지하는 별도 행에 배치하며, 이미지가 없으면 미등록 상태를 표시합니다.
- 비활성화와 영구 탈퇴의 처리 유형, 코드화된 사유, 처리 상태, 요청일, 삭제 예정일, 처리일 및 복구일을 제공합니다.
- 자유 입력 상세 사유와 외부 연동 오류문구는 관리자 API와 화면에 제공하지 않습니다.
- 관리자 화면에서 비활성화 복구, 영구 탈퇴 취소, 유예기간 변경 및 즉시 삭제를 수행할 수 없습니다.
- 유예기간이 끝나 사용자 계정과 프로필 원본이 영구 삭제된 회원은 `현 사용자 관리` 대상에서 제외합니다.
- 회원 원본과 현재 이미지가 물리 삭제된 뒤에는 현재 프로필·배경 이미지 버튼을 제공하지 않습니다. 다만 프로필 사진 신고 시점에 별도 보관한 관리자 전용 증거 원본은 최종 처리 후 180일 보존기간 안에서만 신고 상세에 제공합니다.
- 보존된 회원 계정 처리 이력의 별도 감사 조회 화면은 1차 구현 범위에 포함하지 않습니다.

## 사용자 메뉴 접근 및 보존

- 사용자 화면 메뉴의 사용자 메뉴 트리는 회원별 데이터가 아닌 서비스 전역 운영 설정으로 계정 상태와 무관하게 보존합니다.
- `비활성화`, 영구 탈퇴 대기, `이용정지` 회원은 기존 계정 제한 전용 화면을 우선 표시하며 일반 햄버거 메뉴를 조회하거나 이용하지 않습니다.
- `활성` 상태로 복귀한 회원은 복귀 시점의 최신 사용자 메뉴 트리를 조회하며 비활성화 전 메뉴 구성이나 펼침 상태를 별도로 복원하지 않습니다.
- 사용자 메뉴 구성은 계정 물리 삭제 대상이 아니며, 회원 원본·알림·푸시 구독·독후감·댓글·소셜 관계의 삭제 또는 복원 범위에 영향을 주지 않습니다.

상세 계층 기준은 [메뉴 및 화면 노출 정책](menu-policy.md)을 따릅니다.

## 알림 아이콘 운영 자산

- 알림 아이콘 원본과 관리 정보는 회원이 등록한 파일이 아니라 관리자가 운영 목적으로 관리하는 서비스 전역 자산입니다.
- 알림 아이콘 원본의 아이콘 바이너리와 관리 정보는 회원의 `비활성화`, 영구 탈퇴 대기, 영구 탈퇴 취소 또는 물리 삭제와 관계없이 영구 보존합니다.
- 비활성화 또는 삭제 대기 회원은 일반 알림 목록에 접근할 수 없으며, 기존 수신 알림은 현재 계정 정책대로 삭제 상태로 변경하고 복귀 시 자동 복원하지 않습니다.
- 회원 알림이 삭제되더라도 다른 회원의 알림과 템플릿이 같은 아이콘을 계속 참조할 수 있으므로 아이콘 행은 함께 삭제하지 않습니다.
- 아이콘 이미지에는 개인정보와 민감정보를 포함하지 않으며 인증된 사용자 알림 목록 조회에서만 알림 행과 조인해 제공합니다.
- 알림 아이콘 정책은 알림, 푸시 구독, 독후감, 댓글, 좋아요, 팔로우 및 소셜 관계의 기존 삭제·보존·복원 범위를 변경하지 않습니다.

### 프로필·배경사진 피드 알림

- 프로필·배경사진 좋아요·댓글·답글 알림은 활성 발신자와 활성 수신자 사이에서만 새로 생성합니다.
- 일반 피드에는 활성 상태이며 저장된 공개 범위를 충족하는 로그인 사용자 본인의 현재 공개 독후감과 현재 사진을 포함합니다. 비활성화 또는 영구 탈퇴 대기 중에는 피드 접근과 신규 알림 생성을 중지하며, 활성 복귀 후에도 사진 변경 활동 공개 설정을 자동 복원하지 않습니다.
- 복귀한 사용자가 사진 변경 활동을 다시 표시하도록 직접 설정하면 현재 사진 카드가 일반 피드 조회 조건을 다시 충족할 수 있지만 이전 사진의 과거 변경 카드를 새로 만들지 않습니다.
- 계정 복귀로 삭제된 댓글·좋아요·알림·푸시 구독을 복원하지 않으며, 보존된 현재 공개 콘텐츠만 일반 피드 조회 조건에 따라 다시 노출합니다.
- 수신자가 비활성화 또는 영구 탈퇴 대기로 전환되면 기존 사진 반응 알림을 삭제 상태로 변경하고 복귀 또는 탈퇴 취소 시 복원하거나 재발송하지 않습니다.
- 사진 교체나 반응을 남긴 회원의 물리 삭제로 사진 반응 원본이 삭제되어도 사진 소유자에게 이미 발송된 알림은 해당 수신자의 알림 보존·삭제 정책을 따릅니다.
- 이미 발송된 사진 반응 알림은 저장 당시의 사진 유형과 파일 번호로 현재 사진을 다시 검증합니다. 수신자가 사진 소유자이면 마이페이지, 타인이면 사진 소유자의 공개 프로필로 이동하며, 사진이 교체되었거나 소유자 계정에 접근할 수 없으면 대상 만료 또는 일반 계정 접근 제한을 적용합니다.

세부 등록, 수정 및 표시 기준은 [알림 및 푸시 정책](notification-push-policy.md)을 따릅니다.

## 공지사항 접근 및 보존

- 공지사항 목록, 홈 미읽음 제목 슬라이드, 상세와 본문 이미지는 `활성` 회원에게만 제공합니다.
- `비활성화`, 영구 탈퇴 대기, `이용정지` 회원은 공지사항 화면과 공지 전용 파일 URL에 접근할 수 없습니다.
- 공지사항 상세 조회 이력은 사용자 본인과 시스템만 접근할 수 있는 비공개 데이터로 보존합니다.
- `비활성화`, 영구 탈퇴 대기, `이용정지` 상태에서는 공지 접근과 신규 조회 이력 생성을 중지하며 기존 조회 이력은 유지합니다.
- 공지사항과 공지 전용 첨부 이미지는 관리자 소유 운영 데이터이므로 회원의 비활성화, 영구 탈퇴 요청, 취소 또는 물리 삭제와 관계없이 유지합니다.
- 복귀하거나 영구 탈퇴를 취소한 회원은 기존 공지 읽음 상태를 그대로 사용합니다.
- 유예기간 후 회원이 물리 삭제되면 해당 사용자의 공지 조회 이력도 함께 삭제합니다.
- 공지 조회 이력은 알림, 푸시 구독 또는 소셜 관계에 추가 영향을 주지 않습니다.
- 관리자가 공지 자체를 삭제하면 회원 상태와 관계없이 해당 공지의 모든 사용자 조회 이력을 삭제하며, 재활성화 또는 영구 탈퇴 취소 시 복원하지 않습니다.
- 공지사항 버전과 배포 및 파일 처리의 세부 기준은 [공지사항 운영 정책](notice-policy.md)을 따릅니다.

## 설치형 웹앱 설치 권장 알럿

- 설치 권장 여부는 계정 단위 최초 확인 일시를 기준으로 판정합니다.
- `비활성화`, 영구 탈퇴 대기와 `이용정지` 상태에는 설치 권장 알럿을 표시하거나 확인 일시를 변경하지 않습니다.
- 활성 상태로 복귀하거나 영구 탈퇴를 취소하면 유지한 확인 일시를 사용하며, 확인 이력이 있으면 알럿을 다시 표시하지 않습니다.
- 설치 권장 알럿은 알림을 생성하지 않으며 독후감 공개 설정, 댓글, 좋아요, 푸시 구독 및 소셜 관계를 변경하지 않습니다.
- 실제 설치 여부와 설치 전환 이벤트는 수집하지 않으며 관리자 화면과 통계 API에도 제공하지 않습니다.
- 유예기간이 지나 회원 원본을 물리 삭제하면 사용자 기본정보에 포함된 확인 일시도 함께 삭제합니다.
- 상세 권장, 확인 일시 보존 및 실패 처리 기준은 [설치형 웹앱 설치 권장 알럿 정책](pwa-installation-policy.md)을 따릅니다.

## 등록되지 않은 URL 안내

- 영구 탈퇴 대기 회원이 등록되지 않은 URL에 접근하면 404 안내보다 영구 삭제 대기 전용 화면을 우선 표시합니다.
- `비활성화` 회원은 재로그인 시 기존 계정 활성화 절차를 먼저 적용하며, 활성화가 완료된 뒤 등록되지 않은 URL에 접근한 경우 일반 404 안내를 표시합니다.
- 404 안내는 계정 데이터, 독후감 공개 설정, 댓글, 알림, 푸시 구독 및 소셜 관계를 변경하거나 복원하지 않습니다.
- 등록되지 않은 URL의 화면 노출 기준은 [메뉴 및 화면 노출 정책](menu-policy.md)을 따릅니다.

- 비속어 검사는 각 기능의 입력 권한이 있는 계정의 사용자 작성 문자열 입력 시점에 수행하며 검사 결과와 정규화 중간값을 별도 저장하지 않습니다.
- `이용정지` 계정이 작성할 수 있는 이용정지 이의제기 고객문의 제목과 본문에도 동일한 비속어 검사를 적용합니다.
- `비활성화` 및 영구 탈퇴 대기 계정은 기존 제한 상태 화면과 접근 제어를 적용하므로 콘텐츠 입력을 위한 별도 비속어 검사 경로를 제공하지 않습니다.
- 계정 비활성화, 영구 탈퇴, 취소 또는 복귀 시 비속어 사전과 검사 결과를 기준으로 기존 콘텐츠를 추가 삭제하거나 복원하지 않습니다.
- 비속어 검사 정책은 알림, 푸시 구독 및 소셜 관계의 삭제·보존·복원 범위를 변경하지 않습니다.
- 세부 입력 판정 기준은 [콘텐츠 및 파일 정책](content-file-policy.md)을 따릅니다.

## 도서 검색 제한과 공용 캐시 및 인기 검색어

- 계정 비활성화와 영구 탈퇴 신청 시 도서 검색 접근은 기존 계정 상태 제한에 따라 중단합니다.
- 회원별 Redis 분간 및 일간 검색 제한 카운터는 탈퇴 처리로 제한을 초기화하는 악용을 막기 위해 기존 TTL까지 유지합니다.
- 같은 Kakao 계정으로 재로그인하여 활성화하거나 영구 탈퇴를 취소해도 남은 검색 제한 횟수와 만료시간은 복원하거나 초기화하지 않고 그대로 적용합니다.
- 유예기간이 지나 회원 원본을 물리 삭제할 때 회원별 도서 검색 제한 키도 즉시 삭제합니다.
- 검색어 해시와 카카오 페이지로 공유하는 도서 검색 결과 캐시는 사용자와 연결되지 않으므로 계정 상태 변경으로 삭제하거나 복원하지 않고 기본 10분 TTL까지 유지합니다.
- 계정 비활성화와 영구 탈퇴 신청 중에는 신규 도서 검색이 차단되므로 인기 검색어 점수도 새로 반영하지 않습니다.
- 회원별 인기 검색어 중복 방지 키는 비활성화, 삭제 대기, 복귀 및 탈퇴 취소로 초기화하지 않고 기본 최근 7일의 TTL까지 유지합니다.
- 이미 반영된 정규화 검색어와 익명 일별 점수는 회원 번호와 연결되지 않으므로 계정 상태 변경이나 물리 삭제 시 차감 또는 복원하지 않고 기본 8일 안에 자동 만료합니다.
- 유예기간이 지나 회원 원본을 물리 삭제할 때 회원 번호와 연결된 인기 검색어 중복 방지 키는 즉시 삭제합니다.
- 인기 검색어 집계는 독후감 공개 설정, 댓글, 알림, 푸시 구독 및 소셜 관계에 영향을 주지 않습니다.
- 도서 검색 제한과 공용 캐시는 독후감 공개 설정, 댓글, 알림, 푸시 구독 및 소셜 관계에 영향을 주지 않습니다.
- 주간·월간·연간 인기 도서는 회원 상태, 독서 상태 및 공개 여부와 관계없이 독후감에 남아 있는 각 현재 기간 독후감의 고유 작성자 수를 집계합니다.
- 인기 도서 평균 평점은 도서 정보와 동일하게 읽는 중을 제외한 전체 완료·중단 독후감으로 계산하며 회원 상태와 공개 여부를 조건으로 사용하지 않습니다.
- 계정 비활성화, 영구 탈퇴 신청, 정지, 재활성화 및 탈퇴 취소로 기간별 인기 도서 집계 포함 여부를 변경하지 않습니다.
- 유예기간이 지나 회원의 독후감이 물리 삭제되면 해당 독후감은 모든 기간의 인기 도서 순위와 평균 평점 집계에서 영구 제외되며 별도 이력으로 복원하지 않습니다.
- 기간별 인기 도서 집계는 독후감 공개 설정, 댓글, 알림, 푸시 구독 및 소셜 관계를 변경하지 않습니다.
- 세부 호출 한도와 캐시 기준은 [도서 검색 및 외부 API 쿼터 보호 정책](book-search-policy.md)을 따릅니다.

## 독후감 번역 캐시와 월간 사용량

- 계정 비활성화와 영구 탈퇴 대기 중에는 독후감 원문과 번역 캐시를 유지하되 기존 공개 및 계정 상태 접근 제한을 그대로 적용합니다.

- 독후감 번역은 독후감 공개 설정, 댓글, 알림, 푸시 구독 및 소셜 관계를 변경하거나 복원하지 않습니다.
- 세부 번역 요청과 한도 기준은 [독서 및 독후감 정책](reading-report-policy.md)을 따릅니다.
