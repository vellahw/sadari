# Sadari 공개 기술 문서

## 개요

- 목적: 서비스 정책, 기술 설계, 성능 개선, 운영 절차와 포트폴리오 설명을 공개 범위에 맞게 제공합니다.
- 적용 범위: `docs` 아래의 모든 Markdown 문서입니다.
- 기준일: 2026년 9월 8일입니다.

## 공개 표기 원칙

공개 문서는 구현을 이해하는 데 필요한 업무 흐름과 기술적 판단을 제공하되 데이터베이스의 물리 테이블명, 컬럼명, 인덱스명, 제약조건명과 저장 루틴명은 기록하지 않습니다. 데이터 구조는 다음 기준으로 설명합니다.

- 물리 테이블명 대신 사용자 기본정보, 독후감, 신고 접수 이력처럼 저장 대상과 책임을 설명합니다.
- 물리 컬럼명 대신 사용자 식별번호, 처리 상태, 대상 내용 스냅샷처럼 값의 의미를 설명합니다.
- 인덱스와 제약조건은 동일 요청 중복 방지, 사용자별 최신 목록 조회처럼 보장하는 정합성과 성능 목적을 설명합니다.
- 상태와 분류값은 내부 코드 문자열 대신 사용자 또는 운영 화면의 표시명으로 설명합니다.
- 구현 근거의 소스 경로와 클래스·메서드명은 오픈소스 확인을 위해 유지하되 운영 데이터와 비밀값은 포함하지 않습니다.

## 제한사항

문서의 논리 명칭은 면접과 설계 검토를 위한 공개 설명입니다. 실제 물리 스키마나 운영 기준정보가 필요한 작업은 접근권한이 통제된 원본과 현재 실행 환경을 기준으로 검증해야 합니다.
